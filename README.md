# ケミラボ ― 化学反応研究所

大学レベルの化学を「実験しながら」学ぶ、スマートフォン向けの化学反応シミュレーションゲーム。
見習い研究者として物質を組み合わせ、温度・圧力・触媒・溶媒などの条件を変えて反応を起こし、物質図鑑・反応図鑑を埋めていく。

- サーバー不要・ビルド不要（HTML / CSS / JavaScript のみ）
- GitHub Pages で無料公開、オフラインでも動作（PWA）
- 進行状況は自動保存

設計の詳細は [docs/DESIGN.md](docs/DESIGN.md) を参照。

## 現在の状態：Phase 1（v0.1.0）

- 実験室：試薬の選択（最大 3 種）・温度／圧力／触媒／溶媒／光照射・点火の設定・反応演出
- 反応判定エンジン：条件によって生成物が変わる反応、条件不足による失敗とヒント、「反応しない」組み合わせの解説
- 結果解説：反応式・構造式・分子量・反応機構・反応が進む理由・熱化学・関連知識・安全メモ・検証状況と参考文献
- 物質図鑑（47 種）・反応図鑑（25 反応）
- 生成物の再利用による多段階合成（例：エタノール → エチレン → ブロモヒドリン）
- セーブデータの書き出し／読み込み

## 公開方法（スマートフォンから）

1. GitHub のリポジトリ画面 → **Settings** → **Pages**
2. **Source** を「Deploy from a branch」、**Branch** を `main`、フォルダを `/ (root)` にして保存
3. 数分後、`https://<ユーザー名>.github.io/chem-game/` で遊べる
4. ブラウザの「ホーム画面に追加」でアプリのように起動できる（セーブデータの保護にも有効）

## 化学データの追加

コードを変更せず、`data/` 以下の JSON を編集するだけで追加できる。

| ファイル | 内容 |
|---|---|
| `data/elements.json` | 元素（原子量・表示色） |
| `data/substances.json` | 物質（化学式・物性・構造式・解説） |
| `data/reactions.json` | 反応（反応物・生成物・条件・反応機構・出典・検証状況） |
| `data/non_reactions.json` | 反応しない組み合わせとその理由 |

追加後は、次のいずれかで検証する：
- ゲームの **設定 → 化学データの検証**
- GitHub の **Actions** タブ（push ごとに自動実行）
- PC がある場合：`npm test`

検証内容：反応式の原子数・電荷の保存、ID 参照の整合、構造式と化学式の原子数の一致、出典・検証状況の記載。

## 化学的正確性について

反応データは教科書等に基づいて作成しているが、現時点ではすべて **AI 作成・専門家による査読待ち（`review: "ai-draft"`）** である。
化学の専門家が確認したものは `"human-reviewed"` に変更する。ゲーム用の簡略化を含む反応は `level: "simplified"` とし、何を簡略化したかを画面にも表示する。

**ゲーム内の実験には現実では危険なものが含まれる。ゲームを参考に実際の実験を行わないこと。**

## ファイル構成

```
index.html            エントリーポイント
sw.js                 Service Worker（オフライン用。ファイル追加時は PRECACHE と CACHE_VERSION を更新）
css/style.css         スタイル
js/core/              ゲームロジック（DOM 非依存：ブラウザと Node の両方で動作）
  formula.js          化学式の解析・分子量
  engine.js           反応判定エンジン
  db.js               データ読み込み・索引
  validate.js         データ検証
  store.js            セーブデータ
js/ui/                画面（実験室・結果・図鑑・設定・構造式描画）
data/                 化学データ（JSON）
tools/                検証スクリプトとテスト
docs/DESIGN.md        設計書
```
